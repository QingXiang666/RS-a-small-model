# RS-A-small-model
《融合图神经网络与深度交叉网络的多行为仿真双塔召回模型》

本项目设计并实现了一个面向多行为推荐的双塔召回模型，并将图神经网络与深度交叉网络进行了融合。在MovieLens-1M（3900个用户对6040个电影的100万条评分）数据集上仿真多行为场景（评分→点击，高分→点赞），并按时间序划分训练/验证/测试集，最终达到了Recall@10=3.3%，AUC=0.82的测试结果。

1.使用三层GCN对用户-物品交互图建模，将图结构embedding与ID embedding拼接作为双塔输入，增强冷启动物品和长尾物品的表示能力。

2.用户塔：基于用户行为序列（最近N条点击/点赞记录）通过平均汇聚与DCN交叉网络，输出点击偏好与点赞偏好两个独立向量，支持多目标优化；物品塔：融合物品特征与类型特征经DCN生成统一物品表示，使用余弦相似度计算匹配分数，Margin Hinge Loss联合优化双任务。

3.采用Pairwise训练方式并结合Batch内负采样与logQ修正，有效提升了负样本多样性并消除流行度偏差。
