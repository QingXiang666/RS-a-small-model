# RS-A-small-model
《融合图神经网络与深度交叉网络的多行为仿真双塔召回模型》

本项目设计并实现了一个面向用户多行为的双塔召回模型，将GNN、用户行为序列模型与DCN有机融合，可以同时捕捉图结构特征与交叉特征，适用于多行为推荐场景并提升了推荐系统在复杂用户行为下的表达能力。模型基于用户对电影的100万条评分记录，仿真模拟有评分为点击、评分达到4分为点赞，并按照时间顺序和固定比例对数据集进行划分，在MovieLens-1M数据集上取得了Recall@10=3.3%、AUC=0.82的测试结果。
1.引入三层GCN对用户-物品交互图进行消息传递，分别得到用户和物品的embedding，并将GCN的输出与原始用户或物品ID嵌入拼接作为双塔输入，有效提升了冷启动与长尾物品的表示质量。
2.用户塔中使用用户行为序列模型，分别选出用户对电影的最近10条有点击和点赞的记录，将其中电影的嵌入经过平均汇聚后分别与用户嵌入进行拼接并构成用户塔一侧DCN的输入，最终输出两个独立的点击/点赞偏好向量；融合物品嵌入与电影类型特征构成物品塔一侧DCN的输入，通过DCN生成统一的物品表示。最终相似度计算采用余弦相似度，且模型使用Margin Hinge Loss联合优化点击与点赞任务，可以支持多目标优化。
3.采用Pairwise训练方式、Batch内负采样和logQ修正技术，可以大幅提升负样本多样性并消除流行度偏差。
4.本项目可以为后续粗排和精排模型提供参考，为引入注意力机制与知识蒸馏等优化策略提供良好基础。
